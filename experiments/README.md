# Validation and ablation experiments

Scripts that produce the quantitative validation and ablation results reported in the paper.
Run them from the repository root. Outputs are written to `experiments/out_*`
directories (git-ignored).

| Script | What it does | Paper artifacts |
|---|---|---|
| `detection_validation.py` | Scores the held-out test set with the deployed detector (top-k aggregated PLL-difference), the max-token variant, and the raw-PLL (no-PCGU) baseline; computes precision/recall/F1/FPR sweeps, ROC-AUC, pairwise ranking accuracy, and per-category breakdowns | Detection validation results (Section 4.2.2) |
| `threshold_recalibration.py` | Splits the test set in half at the template level, selects thresholds on the calibration half under four criteria (Youden's J, F1, precision-constrained recall, balanced accuracy), and evaluates on the held-out half | Threshold selection/validation analysis (Section 4.2.2) |
| `gpt4o_ablation_generate.py` | Rewrites the 42 ablation stimuli under three conditions (full pipeline / sentence-flag only / no analysis) with identical prompt, model, and decoding settings; requires `OPENAI_API_KEY` | Generation-ablation conditions (Section 4.3) |
| `gpt4o_ablation_evaluate.py` | Computes surface overlap (character-bigram Jaccard), residual detector scores, and paired Wilcoxon tests over the ablation outputs | Generation-ablation metrics (Section 4.3) |
| `regenerate_table5.py` | Recomputes the per-token PLL example table with the final checkpoint | Table 5 |
| `token_agreement_analyze.py` | Given completed annotation sheets (three annotators, 77 sentences), computes Fleiss' kappa, top-1/top-5 hit rates, and word-level precision/recall/F1 of the system highlights | Token-level human agreement analysis |

The blinded human-rating and token-annotation instruments are generated by the
ablation scripts; the slot-to-condition keys must be kept separate from raters
and annotators until data collection is complete.
